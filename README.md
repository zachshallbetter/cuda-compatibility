# pages-redirect

Redirect-only GitHub Pages content for the retired address `https://zachshallbetter.github.io/cuda-compatibility/`. Each former page names its `https://cudacompat.com/` equivalent as canonical and refreshes to it immediately; any other path falls through `404.html` to the same path on `cudacompat.com`.

The project site and source live on `main`. Keep this branch until Search Console no longer reports the old URLs, then disable Pages.
