Search and AI discovery

What this project makes accessible to crawlers, how its discovery files work, and what has, and has not, been observed.

The site is prepared with crawlable HTML pages, internal links, canonical URLs, an XML sitemap, a robots policy, and an informal llms.txt index. These make content easier to request and interpret; none proves a search engine indexed a page or an AI system retrieved, cited, or recommended it.

C

How AI references are evaluated

A visible answer that names this project is an answer mention. A linked citation is evidence that the answer referenced a URL. Neither proves the system retrieved that page; verified retrieval requires a direct trace from an instrumented system. A citation also does not prove that the answer represented the source accurately.

For any future sample, the project records the product and model version when available, date, locale, exact query, answer, cited URLs, source snapshot, scoring rubric, and limitations. One answer is not a census, and changing metadata or llms.txt alone does not prove an effect.

D

Connect search measurement

The project owns cudacompat.com, and https://cudacompat.com/ is the canonical address. Add a URL-prefix property for https://cudacompat.com/, or a Domain property for cudacompat.com verified by a DNS record. In Search Console, use the exact verification method and token provided for that property. For HTML-tag verification, add its meta tag to the homepage head and keep it there; never invent or reuse a token. Then submit the sitemap and inspect the homepage and key docs URLs.

After Search Console verification, Bing Webmaster Tools can import the verified site and sitemap. This requires signing into the Google account and granting Bing access during the import flow. Alternatively, use Bing’s offered XML-file or meta-tag verification, then submit the same sitemap and review submission status, last-read date, and processing errors.

Report each platform, property prefix, observation window, extraction date, and missing data separately. Search Console or Bing reporting does not guarantee indexing or ranking. Official guides: Search Console properties, ownership verification, Bing site import, Bing sitemap processing.

First-party analytics is configured with a GA4 measurement ID. It loads without a prompt and never contacts Google measurement services from a browser that sends Global Privacy Control or Do Not Track or has opted out. It records only the documented page-view and allowlisted link events. Read the privacy and measurement guide for current settings and limitations.

E

Support claims have their own evidence

Search visibility does not establish CUDA compatibility. For hardware and workload support, use the operation-by-operation support matrix and the reproduction records. A GPU name, compute capability, profile match, version query, search result, or AI recommendation is not a workload certification.

Discovery policy: robots.txt, sitemap, agent index, privacy and measurement.
