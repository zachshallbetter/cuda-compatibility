Agent-readable index ↗

The site is prepared with crawlable HTML pages, internal links, canonical URLs, an XML sitemap, a robots policy, and an informal llms.txt index. These make content easier to request and interpret; none proves a search engine indexed a page or an AI system retrieved, cited, or recommended it.

What can be requested

Current observation state

The public GitHub Pages site is live. The latest release audit fetched all 10 sitemap pages, sitemap.xml, robots.txt, llms.txt, favicon.svg, and both social-card assets successfully. These point-in-time HTTP checks establish availability, not search indexing or audience reach.

Google Search Console auto-verified its URL-prefix property by HTML tag on 2026-11-01. Its sitemap report still says “Couldn't fetch” with zero discovered pages. URL Inspection says the homepage is unknown to Google's index and detects no referring sitemap, while the live URL test says the page is available to Google and can be indexed. It is not currently indexed; no indexing request receipt is recorded. Bing Webmaster Tools verified its owner through meta-tag authentication, and its sitemap now reports Success with 10 URLs discovered and zero errors or warnings. These vendor reports describe distinct processing states. The consent-gated GA4 tag is deployed. One explicitly accepted test visit produced page_view, first_visit, and session_start in GA4 Realtime; test consent was withdrawn afterward. This single test is not audience coverage. No search impressions, indexed-page sample, AI retrieval trace, answer citation, or referral outcome is claimed. Public accessibility is verified; discovery and engagement remain unmeasured.

How AI references are evaluated

A visible answer that names this project is an answer mention. A linked citation is evidence that the answer referenced a URL. Neither proves the system retrieved that page; verified retrieval requires a direct trace from an instrumented system. A citation also does not prove that the answer represented the source accurately.

For any future sample, the project records the product and model version when available, date, locale, exact query, answer, cited URLs, source snapshot, scoring rubric, and limitations. One answer is not a census, and changing metadata or llms.txt alone does not prove an effect.

Connect search measurement

This project is hosted below the shared github.io domain. Add a URL-prefix property for https://zachshallbetter.github.io/cuda-compatibility/; a Domain property would require DNS control for github.io, which project maintainers do not have. In Search Console, use the exact verification method and token provided for that property. For HTML-tag verification, add its meta tag to the homepage head and keep it there; never invent or reuse a token. Then submit https://zachshallbetter.github.io/cuda-compatibility/sitemap.xml and inspect the homepage and key docs URLs.

After Search Console verification, Bing Webmaster Tools can import the verified site and sitemap. This requires signing into the Google account and granting Bing access during the import flow. Alternatively, use Bing’s offered XML-file or meta-tag verification, then submit the same sitemap and review submission status, last-read date, and processing errors.

Report each platform, property prefix, observation window, extraction date, and missing data separately. Search Console or Bing reporting does not guarantee indexing or ranking. See the official guides for Search Console properties, ownership verification, Bing site import, and Bing sitemap processing.

Optional first-party analytics is configured with a GA4 measurement ID and requires affirmative visitor consent before contacting Google measurement services. It records only the documented page-view and allowlisted link events. Read the privacy and measurement guide for current settings and limitations.

Support claims have their own evidence

Search visibility does not establish CUDA compatibility. For hardware and workload support, use the operation-by-operation support matrix and the reproduction records. A GPU name, compute capability, profile match, version query, search result, or AI recommendation is not a workload certification.
