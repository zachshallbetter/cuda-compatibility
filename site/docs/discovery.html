Agent-readable index ↗

The site is prepared with crawlable HTML pages, internal links, canonical URLs, an XML sitemap, a robots policy, and an informal llms.txt index. These make content easier to request and interpret; none proves a search engine indexed a page or an AI system retrieved, cited, or recommended it.

What can be requested

HTML pagesHuman-readable project overview, install steps, operation limits, hardware catalog, and research records.Local page rendering proves only that the current files render in the tested browser.
robots.txtDeclares crawler preferences. Search and user-requested retrieval agents are allowed; selected model-training agents are disallowed.Robots rules are voluntary crawler guidance, not authentication or access control.

Current observation state

The local candidate has passed static metadata, link, sitemap, robots, and route checks. The public GitHub Pages deployment has not been verified for this revision. Search Console is not connected, and the site has no GA4 measurement ID. No live search indexing, search impressions, AI answer mentions, citations, or referral outcomes are recorded.

Accordingly, public accessibility, indexing, AI retrieval, engagement, and conversion remain unknown. A local HTTP 200 or a crawler permission cannot upgrade those states.

How AI references are evaluated

A visible answer that names this project is an answer mention. A linked citation is evidence that the answer referenced a URL. Neither proves the system retrieved that page; verified retrieval requires a direct trace from an instrumented system. A citation also does not prove that the answer represented the source accurately.

For any future sample, the project records the product and model version when available, date, locale, exact query, answer, cited URLs, source snapshot, scoring rubric, and limitations. One answer is not a census, and changing metadata or llms.txt alone does not prove an effect.

Search measurement after publication

Once a public deployment is authorized and verified, the site owner can connect Google Search Console and submit the canonical sitemap. Search impressions, clicks, indexed-page samples, and query/page data should be reported with the property, date range, extraction method, and missing data. Average position is not a universal rank.

Optional first-party analytics remains disabled until a site owner configures a GA4 measurement ID. If enabled, it requires affirmative visitor consent and records only the documented page-view and allowlisted link events. Read the privacy and measurement guide before configuring it.

Support claims have their own evidence

Search visibility does not establish CUDA compatibility. For hardware and workload support, use the operation-by-operation support matrix and the reproduction records. A GPU name, compute capability, profile match, version query, search result, or AI recommendation is not a workload certification.
