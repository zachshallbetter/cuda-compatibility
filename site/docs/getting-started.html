Install CUDA Compatibility for an older NVIDIA GPU

CUDA Compatibility helps users test selected CUDA 13 PyTorch paths on older NVIDIA GPUs while keeping hardware identity truthful.

Install the package into the same Python environment as the CUDA-enabled PyTorch wheel. The launcher builds a process-local adapter and starts your script as a child process; it does not install or replace the system driver.

Requirements

  • Linux x86_64.
  • All visible GPUs must report compute capability 5.2.
  • Python 3.10 or newer; the tested environment uses Python 3.10.12.
  • Official PyTorch 2.14.0 CUDA 13.0 wheel in the active environment.
  • LLVM/Clang 23.1.4 with NVPTX support.
  • CUDA 12.4 development headers, a working driver interface, g++, and C++ headers.

The package bundles no NVIDIA toolkit files, runtime libraries, headers, or drivers. The current launcher uses user-installed CUDA 12.4 development headers with the existing driver stack.

1. Clone the project and create an environment

git clone https://github.com/zachshallbetter/cuda-compatibility.git
cd cuda-compatibility
python3 -m venv .venv
. .venv/bin/activate

If you already have a dedicated environment containing the target PyTorch wheel, activate it instead. The command must use that same interpreter.

2. Install the package

python -m pip install .

For development, use python -m pip install -e .. In a virtual or Conda environment, the command is installed into that environment’s bin/ directory. Avoid system-wide sudo pip installs.

Distribution status: no CUDA Compatibility package is currently published on PyPI. Install from the GitHub checkout using the steps above; pip install cuda-legacy-compat is not a supported installation command.

3. Check the machine

cuda-legacy inspect
cuda-legacy profiles show pytorch-2.14-cu130
cuda-legacy doctor --llvm-root /path/to/LLVM-23.1.4

doctor checks prerequisites; “ready” is not a workload certification. Pass --cuda-root when development headers are not under /usr/local/cuda-12.4.

4. Launch a script

cuda-legacy run \
  --llvm-root /path/to/LLVM-23.1.4 \
  --cuda-root /usr/local/cuda-12.4 \
  -- path/to/app.py --your-option value

The adapter is opt-in and affects only the child Python process. It sets LD_PRELOAD and a Python startup hook, builds temporary bridge/kernel files, and removes those files when the child exits. Use the launcher only with scripts you trust.

Tested configuration

Linux x86_64 · Python 3.10.12 · PyTorch 2.14.0 + CUDA 13.0 · NVIDIA R580 driver · GM200 Maxwell sm_52 · LLVM/Clang 23.1.4 · CUDA 12.4 development headers. Hardware and workload claims are described on the support matrix.
