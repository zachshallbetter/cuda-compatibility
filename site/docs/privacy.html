Privacy and measurement

How site analytics work, how to opt out, which interactions are measured, and how to connect the published site to Google Search Console and Bing Webmaster Tools.

The site is a static site served by Vercel. The project does not enable Vercel Web Analytics or analyze request logs. A GA4 web stream is configured, and its tag loads without a prompt unless the browser asks sites not to track or the visitor opts out below.

A

What the site measures

After opt-in, the site sends a page view using the page path, static page title, and referrer origin. It records clicks on a short list of installation, support matrix, GPU catalog, repository, source download, evidence, discovery guide, and external reference links, with the page area of the link (header, footer, sheet index, or content). External link events include only the destination host. It also records a successful press of a command copy button, naming only the step (clone, install, or check), and a press of the hero replay button. Paths omit query strings and fragments. The event code does not collect form values, model inputs, free text, or the full destination URL.

Named events after opt-in
page_viewinstallation_guide_clicksupport_matrix_clickgpu_catalog_clickproject_repository_clickevidence_page_clickdiscovery_page_clickexternal_reference_click

GA4 also automatically records first_visit, session_start, and user_engagement when the tag loads. The site downloads its Archivo and Martian Mono font files from its own origin and does not request font files from Google or another font host.

Google Analytics may receive browser and device information and an IP address, use the address to infer approximate location, and set first-party cookies to distinguish browsers and sessions. Google says GA4 uses IP addresses at collection time and discards them before data is logged. Advertising storage, advertising user data, and personalization signals are denied by the site tag. Google Signals, user-provided data collection, ads personalization, and Enhanced Measurement are also off in the Analytics property. This is a data-minimization design, not a legal-compliance certification.

Opting out blocks this site’s named events, updates Google’s consent state to denied, and attempts to remove GA cookies on the current host before reloading. Google may still process that consent update or limited signals. This control cannot delete data already sent to Google; deletion must be requested through the Analytics property.

Google’s documentation on Analytics data handling, automatically collected events, and data retention.

B

Opting out

The site shows no analytics prompt. The Google tag never loads in a browser that sends Global Privacy Control or Do Not Track. Anyone else can turn analytics off with the button below; the choice is stored only in this browser, and the project does not receive it. An earlier “Reject” choice from the old prompt is still honoured. Advertising storage, Google signals and ad personalisation stay off for every visitor.

Google’s documentation describes the Analytics consent types, the GA4 event model, and data retention settings.

C

Configure analytics

  • The project GA4 property and web stream are configured.
  • Enhanced Measurement is off so the property does not add automatic scroll, form, or outbound-click events.
  • Event-level retention is two months. Email redaction is on, and URL redaction covers email, token, access_token, and code parameters. Google Signals, user-provided data collection, and ads personalization are off at the property level; advertising signals are denied by the site tag.
  • The stream Measurement ID is configured in analytics.js; the tag is deployed and loads without a prompt, except for opted-out browsers.
  • A consented setup test on 2026-11-01 produced page_view, first_visit, and session_start in GA4 Realtime. Test consent was then withdrawn. This one test confirms event receipt only, not audience coverage or outcomes.
D

Connect Google Search Console

Verified, homepage indexed
1Publish the site at https://cudacompat.com/ and confirm it returns public pages over HTTPS.
2In Google Search Console, add a URL-prefix property for that exact site address.
3Choose HTML-tag verification, copy the verification value, and add the provided google-site-verification meta tag to the homepage head. Keep Google’s exact token unchanged.
4After verification, submit sitemap.xml in the Sitemaps report.
5Use URL Inspection for the homepage and key documentation pages. A crawl or indexing request is not a guarantee of indexing, ranking, or timing.

The sitemap and crawler policy are available at sitemap.xml and robots.txt. The cudacompat.com Domain property is verified. On 2026-11-03 Search Console read the sitemap as Success with 10 discovered pages, and URL Inspection reported the homepage indexed; index status for the other pages is not yet reported. The 2026-11-01 receipts cover only the retired GitHub Pages address.

Google’s guidance on requesting a crawl and submitting a sitemap.

E

Connect Bing Webmaster Tools

Verified, sitemap read
1Open Bing Webmaster Tools and choose Import from Google Search Console after the URL-prefix property above is verified. Review the account-access request before granting it.
2If you do not want to import, add this exact site prefix in Bing and complete the verification method Bing offers, such as its XML file or meta tag. Keep the supplied verification artifact in the published site; do not invent a token.
3Submit sitemap.xml in the Sitemaps section.
4Check submission status, last-read time, and reported processing errors. Record the date and property prefix with any result; submission alone does not show that pages were indexed.

Bing imported cudacompat.com from Search Console and on 2026-11-03 crawled its sitemap with Success: 10 URLs discovered, zero errors, zero warnings. That confirms discovery, not indexing.

Bing documents importing verified Search Console properties, site verification methods, and sitemap submission and processing.

F

Measurement is not proof of reach

Analytics can describe measured visits and link clicks. Search Console reports search impressions, clicks, and indexing signals. Neither proves a visitor found the site through a particular recommendation, nor guarantees search visibility. The project will report each metric with its observation window and data source.
