B

Before you install

Tested run path

Linux x86_64, Python 3.10.12, PyTorch 2.14.0 with CUDA 13.0, LLVM/Clang 23.1.4, CUDA 12.4 development headers, a working NVIDIA driver, and only visible sm_52 GPUs. Other setups are not yet qualified.

Read the documentation as a support contract

“Available,” “experimental,” “contradicted,” “unverified,” and “unknown” are separate evidence states, each backed by a named record or by the absence of one. Unverified means no record; unknown means the fact was not observable in the recorded environment. A profile match or a successful CUDA version query does not certify an application. Check the exact operation, dtype, shape, library path, and device before relying on a result.

C

Search and assistant access

The site publishes crawler preferences and a page sitemap. Search and user-requested retrieval crawlers are allowed; selected model-training crawlers are disallowed. Robots rules are voluntary crawler instructions, not access control, and they do not guarantee fetching, indexing, or citations. See the OpenAI crawler guidance, Anthropic crawler guidance, and Perplexity crawler guidance.

D

Asking for support

Include the tool version, OS, Python, PyTorch, and CUDA versions, GPU compute capability, the failing operation, and a small reproducer. Do not attach model weights, secrets, or private input data.

General notes, all sheets
  1. Marks: filled is reproduced on the reference configuration; hatched is reproduced for the listed cases only; crossed is contradicted with the observation kept; outline is unverified or unknown. Every mark names its record.
  2. Unverified means no record exists and is not refutation. Unknown means the fact was not observable in the recorded environment.
  3. Commands are shown and copyable. Nothing runs from a sheet; selected is not executed.
