Before you install

The tested run path requires Linux x86_64, Python 3.10.12, PyTorch 2.14.0 with CUDA 13.0, LLVM/Clang 23.1.4, CUDA 12.4 development headers, a working NVIDIA driver, and only visible sm_52 GPUs. Other setups are not yet qualified.

Search and assistant access

The site publishes crawler preferences and a page sitemap. Search and user-requested retrieval crawlers are allowed; selected model-training crawlers are disallowed. Robots rules are voluntary crawler instructions, not access control, and they do not guarantee fetching, indexing, or citations. See the OpenAI crawler guidance, Anthropic crawler guidance, and Perplexity crawler guidance.

Use the documentation as a support contract

“Available,” “experimental,” and “unverified” are separate evidence states. A profile match or a successful CUDA version query does not certify an application. Check the exact operation, dtype, shape, library path, and device before relying on a result.

For support requests, include the tool version, OS, Python/PyTorch/CUDA versions, GPU compute capability, failing operation, and a small reproducer. Do not attach model weights, secrets, or private input data.
