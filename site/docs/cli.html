cuda-legacy command reference

CUDA Compatibility helps users test selected CUDA 13 PyTorch paths on older NVIDIA GPUs while keeping hardware identity truthful.

cuda-legacy is the preferred terminal command. Install it into the same Python environment as the CUDA-enabled PyTorch package. The previous cuda-legacy-compat command remains an alias.

General commands

CommandPurpose
cuda-legacy --helpList commands and example use.
cuda-legacy help <command>Show command-specific guidance.
cuda-legacy --versionPrint the installed package version.
cuda-legacy inspect [--json]Report visible GPU and compiler inventory as JSON.
cuda-legacy profiles list [--json]List bundled versioned compatibility profiles.
cuda-legacy profiles show PROFILE [--json]Explain a profile’s source and requirements.
cuda-legacy doctor [--llvm-root PATH] [--cuda-root PATH] [--json]Check prerequisites for the experimental launcher.
cuda-legacy audit PROFILE [--json]Compare available machine facts against a target profile.
cuda-legacy run [options] -- SCRIPT [args...]Start a Python script with the opt-in adapter.

Launch options

cuda-legacy run \
  --llvm-root /path/to/LLVM-23.1.4 \
  --cuda-root /usr/local/cuda-12.4 \
  -- path/to/app.py --application-option value

You can set CUDA_COMPAT_LLVM_ROOT and CUDA_COMPAT_CUDA_ROOT instead of passing the corresponding path options. The script and its arguments go after the -- separator.

Exit codes

  • doctor: 0 when checked prerequisites are ready; 1 when setup needs attention.
  • audit: 0 compatible against recorded profile fields; 1 incompatible; 2 invalid/unreadable profile; 3 required facts unknown.
  • profiles: 0 on success; 2 when a profile cannot be read or resolved.
  • run: returns the child application’s exit code; launcher preflight/build errors return 2.

“Compatible” and “ready” refer only to fields each command checks. Neither is an operator or workload certification.

Common setup errors

  • Missing GPU inventory means nvidia-smi is unavailable; the package does not install drivers.
  • LLVM must be version 23.1.4 and include bin/clang++ with NVPTX support.
  • CUDA headers must include cuda.h and cuda_runtime.h.
  • The current adapter accepts only visible sm_52 devices. Numeric CUDA_VISIBLE_DEVICES selections can restrict a mixed host.
  • “No kernel image” means the wheel lacks an image for that operation and no registered replacement path handled it.

See the support matrix before treating a preflight pass as application support.
