Legacy GPU
compute capability

A guide to the older GPU generations in NVIDIA’s legacy CUDA list, with plain-language context and an honest view of what this project has tested.

Read this before choosing a card: compute capability describes a GPU’s hardware feature and instruction level. It is not a CUDA Toolkit version, driver version, performance score, or promise that a current software package supports the GPU.

How to use this page

Three different questions

The original NVIDIA page maps device models to compute capability. This companion adds interpretation and separates that hardware fact from software and project qualification.

01

What is the hardware level?

The number such as 5.2 identifies the GPU architecture’s published capability. Similar numbers often group devices from the same generation, but exact features still vary by chip.

02

Will a CUDA release support it?

That is a separate toolkit, compiler, driver, and library policy. NVIDIA’s CUDA 13 notes removed toolkit offline compilation and library support for Maxwell, Pascal, and Volta; a listed capability alone does not restore that support.

CUDA 13 release notes ↗
03

Has this project tested it?

Only exact configurations with recorded runs count as verified. Today’s experimental launcher accepts sm_52; that is a narrow gate, not certification for every card at that level.

NVIDIA-listed legacy tiers

Capability, context, and project status

Every tier in NVIDIA’s legacy table appears below. Model names are representative examples, not a substitute for NVIDIA’s complete model list. “Unverified” means this project has no recorded qualification for that tier.

7.2UNVERIFIED · OUTSIDE CURRENT GATE

Volta-derived embedded GPUs

A 7.x capability generation for embedded Xavier systems. These devices have their own system, driver, and software packaging constraints; desktop Linux results do not transfer automatically.

Examples: Jetson AGX Xavier, Jetson Xavier NX.

7.0UNVERIFIED · OUTSIDE CURRENT GATE

Volta

Data-center and workstation GPUs from NVIDIA’s Volta generation. The capability is substantially newer than Maxwell, but CUDA 13’s published legacy-support change still matters for toolkit and library paths.

Examples: NVIDIA V100, Quadro GV100.

6.2UNVERIFIED · OUTSIDE CURRENT GATE

Pascal embedded

An embedded Pascal tier. Board image, operating-system release, and JetPack/BSP support are part of the compatibility problem in addition to CUDA APIs.

Examples: Jetson TX2.

6.1UNVERIFIED · OUTSIDE CURRENT GATE

Pascal

Pascal data-center, workstation, and consumer GPUs. CUDA 13 support removal is a software-toolchain boundary, not proof that the silicon cannot perform useful computation.

Examples: Tesla P40/P4, Quadro P6000/P5000/P4000, GeForce GTX 1080/1070/1060/1050.

6.0UNVERIFIED · OUTSIDE CURRENT GATE

Pascal compute

A Pascal data-center and workstation capability tier. The model name and exact product configuration should be checked against NVIDIA’s source table.

Examples: Tesla P100, Quadro GP100.

5.3UNVERIFIED · OUTSIDE CURRENT GATE

Maxwell embedded

Maxwell’s embedded 5.3 tier. It shares a broad generation name with other Maxwell GPUs, but the current adapter requires exact capability 5.2 and does not accept 5.3.

Examples: Jetson Nano.

5.2EXPERIMENTAL · REFERENCE CONFIGURATION

Maxwell GM200 and related devices

This is the only capability accepted by the current adapter. Native kernel and selected PyTorch probes have run on three GM200 reference cards; model-level validation covers only one selected card. Candidate models at 5.2 remain unverified.

Examples: Tesla M40/M60, Quadro M6000/M5000/M4000/M2000, GeForce GTX 980 Ti/980/970/960/950.

5.0UNVERIFIED · OUTSIDE CURRENT GATE

Maxwell GM107-class devices

Another Maxwell tier, found across workstation, consumer, and mobile products. Similar generation does not mean the adapter can target it: current launcher validation is exact sm_52.

Examples: Quadro K2200/K1200/K620, GeForce GTX 750 Ti/750, GeForce GTX 850M/840M/830M.

3.7UNVERIFIED · OUTSIDE CURRENT GATE

Kepler data center

A Kepler compute tier. It predates Maxwell and has distinct hardware and software constraints; a Maxwell code path cannot be assumed to work here.

Examples: Tesla K80.

3.5UNVERIFIED · OUTSIDE CURRENT GATE

Kepler GK110-class

A Kepler tier covering data-center and workstation boards along with consumer products. It requires its own kernel and library qualification.

Examples: Tesla K40/K20, Quadro K6000/K5200, GeForce GTX 780 Ti/780.

3.2UNVERIFIED · OUTSIDE CURRENT GATE

Kepler embedded

Embedded Kepler systems have platform-specific software stacks and are not interchangeable with desktop cards at similar generations.

Examples: Tegra K1, Jetson TK1.

3.0UNVERIFIED · OUTSIDE CURRENT GATE

Kepler GK10x-class

Kepler consumer and workstation devices from an earlier tier than 3.5. Application support depends on available binaries, driver support, and library behavior.

Examples: Tesla K10, Quadro K5000/K4000/K2000, GeForce GTX 770/680/660.

2.1UNVERIFIED · OUTSIDE CURRENT GATE

Fermi refresh

A Fermi-generation capability used by workstation and consumer GPUs. Modern CUDA libraries and frameworks may have removed both prebuilt images and the ability to compile for it.

Examples: Quadro 2000/600, GeForce GTX 560 Ti/460, GeForce GT 520.

2.0UNVERIFIED · OUTSIDE CURRENT GATE

Fermi

Early Tesla, workstation, and consumer compute GPUs. A driver recognizing the board does not imply a modern framework ships usable kernels for it.

Examples: Tesla M2090/C2070, Quadro 6000/5000, GeForce GTX 580/480.

1.3UNVERIFIED · OUTSIDE CURRENT GATE

Tesla generation · compute 1.3

Early CUDA-capable data-center and workstation GPUs. This tier is included for historical reference; it is far outside the project’s current adapter target.

Examples: Tesla C1060/S1070, Quadro FX 5800/4800, GeForce GTX 285/280.

1.2UNVERIFIED · OUTSIDE CURRENT GATE

Tesla generation · compute 1.2

An early CUDA capability tier represented mainly by workstation and mobile products in NVIDIA’s legacy table.

Examples: Quadro FX 380 Low Profile, NVS 300, GeForce GT 240/220.

1.1UNVERIFIED · OUTSIDE CURRENT GATE

Tesla generation · compute 1.1

Early workstation, mobile, and consumer GPUs. Current project tooling has no implementation or qualification for this hardware.

Examples: Quadro FX 3700/1800/580, GeForce 9800 GTX/8800 GT/8400 GS.

1.0UNVERIFIED · OUTSIDE CURRENT GATE

First-generation CUDA capability

The earliest tier in NVIDIA’s legacy CUDA listing. Inclusion here documents the hardware map only; it does not imply current driver, compiler, framework, or library support.

Examples: Tesla C870/D870/S870, Quadro FX 5600/4600, GeForce 8800 GTX/Ultra.

What “listed” means for this project

A model in NVIDIA’s table has a published compute capability. That fact alone cannot supply a missing PyTorch kernel, translate an unsupported instruction, or replace a library that rejects the GPU. Our support status is based on reproducible operation and workload results. At present, the experimental path is limited to Linux x86_64, PyTorch CUDA 13, and sm_52, with selected operations and bounded CPU fallbacks.
